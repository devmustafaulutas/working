# 🧾 Muhasebe Otomasyonu – Python + MySQL

Part-time çalıştığım bir iş yerinde manuel yapılan işler için geliştirdiğim , giriş seviyesi bir **muhasebe otomasyonu** projesidir. Python ile yazılmıştır ve veri yönetimi için **MySQL veritabanı** kullanılmaktadır.

## 🔍 Özellikler

- 💸 Gelir & gider kaydı
- 📊 Günlük & aylık rapor üretimi
- 🧮 Kasa toplam hesaplama
- 🗄️ MySQL veritabanı üzerinden veri saklama ve sorgulama

## 🛠️ Kullanılan Teknolojiler

- Python 3.12.6
- `mysql-connector-python`
- `datetime`
